# orunmila — live demo report

This branch serves one file: the page `orunmila trail` renders, made by the real
renderer from a scripted session built to show one of every claim outcome — a
verified claim, a partial one (a stub), a phantom, a phantom verification, an
unverifiable claim, a silently dropped ask, an undisclosed file, and an untracked
disk write the Sentinel caught — with each of the agent's own edits seen by both
witnesses, and every trail channel (read, write, command, network, disk) and a
sub-agent's touch. It loads nothing from the network.

Not shown: the judge's session verdicts, which need the intake's record.

Made with `npx orunmila demo` from `n10-redo` at e551263 (1.0.0, not yet on npm).
Regenerate it with `npx orunmila demo`. Source: https://github.com/kalkudiary-ai/orunmila
